# Indonesian Used Car Listings Dataset — Carsome.id

A dataset of 611 used-car listings collected from Carsome.id using web scraping.

The dataset is intended for exploratory data analysis, used-car market research, and data-driven projects.

**Dataset statistics (October 20, 2026):**
- Views: 6,603
- Downloads: 1,483

**Potential use cases**
- Exploring used-car prices across vehicle brands and models
- Analyzing relationships between vehicle characteristics and listing prices
- Practicing data cleaning, visualization, and exploratory data analysis

**Source:** [Kaggle — Used Car Listings in Indonesia](https://www.kaggle.com/datasets/indraputra21/used-car-listings-in-indonesia/data), [GitHub](https://github.com/Indra-Putra2/DataScrapping/tree/master/CarListing)

# PCPartPicker RAM Price Dataset — December 2025

A snapshot of RAM product prices collected from PCPartPicker in December 2025.

The data collection process was implemented in C#, while Python was used to clean and prepare the collected data in January 2026.

**Dataset statistics (October 20, 2026):**
- Views: 672
- Downloads: 108

**Potential use cases**
- Exploring RAM product prices and specifications
- Comparing prices across available RAM products
- Practicing data collection, data cleaning, and data analysis

**Source:** [Kaggle — PCPartPicker RAM Dataset](https://www.kaggle.com/datasets/indraputra21/pcpartpicker-ram-dataset), [GitHub](https://github.com/Indra-Putra2/DataScrapping/tree/master/RamPriceAmazon2025)
